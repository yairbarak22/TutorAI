# RuecAI Teacher

עוזר לימודים מבוסס AI, בקוד פתוח, שרץ מקומית אצל הסטודנט (פותחים קישור — אפס התקנה, החומרים לא עוזבים את המחשב) — נבנה ע"י ובשביל הסטודנטים של אוניברסיטת רייכמן.

מעלים את חומרי הקורס (מצגות, PDF, הקלטות הרצאות, מבחנים לדוגמה) ומקבלים: סיכומים, טוטור סוקרטי עם ציטוטים, חידונים, כרטיסיות עם חזרה מרווחת, סימולציות מבחן, הסברים אינטראקטיביים ותלת-ממדיים, ותוכנית לימוד עד המבחן.
